# Canadian InfoLine provider expansion

The regional menu uses the caller's six-digit Canadian numbering assignment to select local news, weather and lottery products. The numbering assignment is a suggested location, so the caller can confirm or override the weather city. Keep actual line numbers out of public-provider requests, persistent caches and diagnostic logs.

## Provider contracts

| Service | Source | Refresh and qualification |
| --- | --- | --- |
| Numbering | [CNA nationwide CO-code ZIP](https://www.cnac.ca/data/COCodeStatus_ALL.zip) | Import assigned, in-service NPA-NXX, exchange area and province. Refresh weekly and retain the last valid snapshot. The November 23 snapshot was retrieved successfully. Shared NPAs require the exchange assignment to distinguish provinces. |
| Weather | [ECCC city search](https://weather.gc.ca/api/accesscity/en?query=toronto&limit=50) and [coordinate lookup](https://weather.gc.ca/api/app/v3/en/Location/47.588,-52.717?type=city) | Match the exchange and province, resolve coordinates to three decimal places, and cache weather for ten minutes. The coordinate API may return a nearby community, so display its actual returned location. Both endpoints returned JSON in local probes. |
| General news | [CBC feeds](https://www.cbc.ca/rss/), [Global News](https://globalnews.ca/feed/), [NTV](https://ntv.ca/feed/), [VOCM](https://vocm.com/feed/) | Cache publisher headlines with source and publication date for 15 minutes. Include CBC national categories, CBC regional feeds, and the two Newfoundland sources. |
| Financial and biotech news | [Headlinefeed REST documentation](https://headlinefeed.dev/documentation) | Bearer credential from local environment. Search MarketWatch by source ID and biotech by title keyword, cache hourly and enforce 100 requests per UTC day. Both query shapes returned results. |
| Stock quotes | [Twelve Data batch and credits](https://twelvedata.com/docs/advanced/batch-requests), [Alpha Vantage API](https://www.alphavantage.co/documentation/) | Hourly cache. Use Twelve Data for the primary watchlist, at most 800 credits/day and eight/minute. Alpha Vantage has a separate 25/day allowance and supplies an end-of-day fallback. Label currency, timestamp and source without claiming realtime data. |
| Banking | [SimpleFIN protocol v2](https://www.simplefin.org/protocol.html), [Bridge limits](https://beta-bridge.simplefin.org/info/developers) | Keep the existing read-only enrollment, call-bound approval code and private route checks. Retrieve recent posted transactions with bounded account and date filters when authorized. Real-account verification awaits the setup token. |

The initial watchlist has five representative US-listed companies in each of four sectors. The selection is configurable and is curated rather than dynamically ranked. At one credit per symbol, a full 20-symbol hourly refresh uses 480 of the 800 daily Twelve Data credits. Batching still charges per symbol. Quotes refresh on demand and reuse the hourly result across all callers. Alpha Vantage fallback symbols require a configured quote currency because its Global Quote response omits currency. Quota accounting and public snapshots are stored in the Compose `provider-cache` volume and survive application restarts.

## Lottery routing

National games include Lotto Max, Lotto 6/49 and Daily Grand. Lotto Max draws occur Tuesday and Friday and its current main draw uses 52 balls. Lotto 6/49 and regional 49 games occur Wednesday and Saturday. Daily Grand occurs Monday and Thursday. Select the local operator by province for regional games and add-on results. Store schedules, product identifiers, endpoints and labels in the provider configuration. Request dated draws and validate the returned draw date before publishing results, including the previous scheduled draw when the expected draw is pending. Display results only with a date and source. ALC provides the common national fallback; local sources supply their own regional add-ons. The three national games are operated by the Interprovincial Lottery Corporation. [BCLC draw explanation](https://corporate.bclc.com/our-business/our-products/lottery/how-are-lottery-numbers-drawn-.html-0)

## Acceptance and remaining access

The standalone terminal may supply a synthetic NANP caller identity when dialing 6501 within the authenticated local lab. The PJSIP caller ID module is required for the gateway to receive it. Public information selection uses only the six-digit prefix. Private banking requires independent enrollment, call approval and a separate administrator-mapped private SIP route; the public InfoLine route has the demo banking option only. The optional `private-infoline` Stasis route is reserved for an independently qualified private endpoint and uses the published InfoLine graph.

## Configuration and operation

The maintained [regional catalogue](../../service/coinline_adsi/regional.json) contains HTTPS endpoints, topics, regional routing, stock sectors, schedules and game identifiers. Modify this file and rebuild the app, or mount a replacement JSON file and set `ADSI_REGIONAL_CONFIG` to its container path. Set `ADSI_REGIONAL_ENABLE=1` in the ignored local `.env` to activate the providers. Install credentials in `ADSI_HEADLINEFEED_KEY`, `ADSI_TWELVE_DATA_KEY` and `ADSI_ALPHA_VANTAGE_KEY`. Keep their values out of Git and console logs. The `regional` boolean in the operator provider settings permits disabling live regional information independently of the other app features. The default CI deployment leaves regional providers disabled and uses synthetic fixtures.

The caller confirms a suggested weather city before querying ECCC; unknown numbering assignments open the manual city/province menus. The `weather.current`, `weather.forecast`, `news.headlines`, `market.quote` and `lottery.draw` operations accept configured catalogue identifiers. Finance includes stock sectors, financial headlines, biotech headlines and bank balance/activity. The graph simulator uses synthetic provider records and displays the banking action prompt. The standalone SIP terminal exercises real location and dynamic provider selection.

The private route is opt-in and uses a separate connection for InfoLine, never another application’s Access URL. The approval prompt does not reveal whether a caller ID is enrolled; only a matching, authenticated web approval unlocks a read. SimpleFIN recent transactions are read after approval, using account/date filters for the last 30 days and showing at most ten posted entries in descending date order. Unlink/revocation is checked before and after the read. Financial records remain in call memory and are excluded from the shared public cache. Bank demo balances and transactions are synthetic.

Test the nationwide prefix import, shared-province NPAs, province override, precise coordinate rounding, nearby-station labels, source dates, RSS parsing, quote quotas and cache reuse, and lottery fallback across draw days. Verify menus over local SIP, including finance, stock categories and banking. Individual provider errors must produce an unavailable indicator, or a clearly dated cached result.
